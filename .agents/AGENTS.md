# プロジェクトルール (法律)

このルールは厳格な法律であり、すべての作業において100%遵守されなければなりません。例外はありません。

## NEVER（違反は即失敗。破る前に必ず相談すること）
- 1コミットで200行を超える変更を確認なしに行わない。
- 秘密情報・APIキー・本番設定を自己判断でリポジトリにコミットしない。
- 自己判断で「完了」と報告しない。完了とは `verify.ps1` / `verify.sh` が `exit 0` で通ること。
- 依存関係（外部ライブラリなど）を勝手に追加しない。提案のみ行い、指示を待つ。
- 要求された仕様（spec）以外の過剰なリファクタリング、抽象化、機能追加を行わない。
- テストや検証コードを削除・スキップして通す行為は、常に失敗とみなす。
- 境界条件以外の起こり得ないケースに対するエラー処理を勝手に追加しない。
- **スプレッドシートの更新・ステータス変更時に重複行を作成しない（必ず既存ID/既存案件を上書き更新すること）。**
- **所属タレントのプロフィール情報（中塚智、島田和奏等）を自己判断で捏造・誤認しない（必ず公式マスターを参照すること）。**

- **会社名**: **GATE株式会社**（※「株式会社GATE」ではなく「GATE株式会社」）
- **ルール**: メール文面、署名、各種ドキュメント出力時は必ずこの正式名称を使用すること。誤表記は厳禁。

- タレントの提案文・メール文・資料作成時は、必ず `.agents/skills/gate-talents-profile/SKILL.md` の公式情報を参照すること。
