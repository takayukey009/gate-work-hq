# Audition Auto Register Skill

このスキルは、ユーザーから提供された打診書（PDF等）を解析し、以下の情報を抽出して各所に登録・更新します。

## 1. 抽出項目
- 案件名（オーディション名）
- 案件種別（オーディション、オファー、レギュラー、撮影、イベント等）
- ジャンル（広告、ドラマ、映画、舞台、Webドラマ等）
- 締切日
- オーディション日程
- 本番日程・撮影期間
- 対象タレント
- 備考（役柄、制作会社、金額、条件等）

## 2. 実行プロセス
1. **解析**: PDFや打診文の内容を正確に読み取り、上記項目を抽出します。
2. **タレントマスター参照**: プロフィールや提案文の作成時は、必ず `gate-talents-profile` スキルの公式情報（生年月日、出身地、身長、特技、出演歴、リールURL）を参照すること。
3. **ダッシュボード登録・更新（重複防止・Upsert厳守）**:
    - 既存案件のステータス変更・更新（「落ちた」「受注した」等）時は、**絶対に新規行を追加しないこと**。
    - 必ず既存の `id` を指定するか、同名タレント×同名案件の行を特定して上書き更新（Upsert）すること。
4. **カレンダー登録**:
    - オーディション日や本番候補日程をカレンダーに登録します。
    - **時間指定**: 時間指定がない場合は「YYYY-MM-DD」形式で指定し、**Googleカレンダー上の「終日」チェックボックスがONになる設定**で登録すること。
    - **タイトル規則**: 未確定・候補日程の場合は「【仮】」をタイトルに付与すること。

## 3. 注意事項・法律
- スプレッドシートの二重登録・重複行作成は厳禁。
- タレント情報（中塚智、島田和奏、谷口彩菜、寺崎ひな等）の経歴・年齢・出身地等の誤表記は厳禁。
